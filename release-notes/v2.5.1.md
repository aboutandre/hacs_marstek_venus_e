# v2.5.1 — Ride out V150 Local API silences

EMS firmware V150 closes the Local API for ~5-30 s on a fixed ~34 min timer. Until now one missed poll made every entity of that battery unavailable for a full 60 s scan interval — dipping a "Fleet SOC" average by a third and dropping the battery out of an external brain's dispatch set for that minute.

### Fixed
- **One missed poll no longer makes the battery unavailable.** The coordinator keeps the last good reading for up to `POLL_GRACE_S` (120 s) and re-polls every `POLL_RETRY_S` (10 s) until the device answers. A battery that stays silent past the grace window still goes unavailable. One INFO line per silence (`<ip> answered again after Ns of silence`) records how long it lasted.
- **"Connection refused" is retried like a timeout** instead of failing the request on the first attempt. A refused attempt waits out the rest of its timeout, so the worst-case request time is unchanged.

### Added
- `tests/test_poll_grace.py` (7 tests).
- Release workflow: a version bump in `manifest.json` on `main` now publishes the GitHub release that HACS installs.
